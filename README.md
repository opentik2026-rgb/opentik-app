# opentik-app

OpenTik Mobile & Smart Systems Application built with React, Vite, and Capacitor.

## Overview
An open-source mobile and technical management solution providing tools for field engineers, network diagnostics, and smart systems automation with offline-first capabilities.

## Tech Stack
- **Framework:** React / Vite
- **Mobile Runtime:** Capacitor
- **Styling & Core:** JavaScript / HTML

## Getting Started

### Installation
```bash
git clone [https://github.com/opentik2026-rgb/opentik-app.git](https://github.com/opentik2026-rgb/opentik-app.git)
cd opentik-app
npm install
npm run dev
